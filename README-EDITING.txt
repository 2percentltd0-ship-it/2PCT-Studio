2 PERCENT WEBSITE — EDITING GUIDE

Open index.html in any browser to view the website locally.

QUICK CONTENT EDITING
- content.js: logo path, email address, project names, categories, text and images
- index.html: homepage headlines, service descriptions and studio text
- styles.css: colours, sizes, spacing, layouts and animations
- script.js: project drawer and navigation behaviour

IMAGES
- logo-2percent.png is the original supplied logo and has not been altered.
- portfolio-contact-sheet.png contains the six temporary project photographs.
- In content.js, imagePosition chooses the relevant photograph for each project.
- To use individual project images, set imageFile inside a project, for example:
  imageFile: 'my-project-image.jpg'
  imagePosition: 'center'
- Put replacement image files in the same folder as index.html.

CONTACT
- Replace hello@2percent.studio inside content.js with the final studio email.

No build tools are required. The website is plain editable HTML, CSS and JavaScript.
